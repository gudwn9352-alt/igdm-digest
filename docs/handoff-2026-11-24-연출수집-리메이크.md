# 인계 문서: "연출 수집 + AI 리메이크" 파이프라인 (2026-11-24 테스트)

이 문서를 읽는 Claude 에게: 2026-11-24 클라우드 세션에서 사용자와 함께 기획·테스트한 내용입니다. **사용자가 무엇을 원했고, 도중에 무엇을 바꾸거나 고쳤는지**를 시간 순으로 정리했습니다. 구현 코드는 이 저장소에 있고, 수집된 영상은 저장소에 없습니다(아래 "파일 위치" 참고).

## 1. 최종 목표 (사용자 표현 기준)

1. **레퍼런스 수집**: 인스타그램 릴스에서 "사람이 나오는" 영상을 키워드별로 10개씩 내려받아, 화면 전환(컷) 기준으로 잘라 원본과 함께 저장.
2. **리메이크로 소스 확보**: 수집한 레퍼런스를 rea-video 방식으로 분석·계획하고 AI 영상 모델로 다시 생성해서 **품질 좋은 자체 소스**를 얻음.
3. **필요 없는 것**: 효과음, 자막 만들기, AI 영상 여부 판정. 목적은 "소스 획득"뿐.
4. **가장 중요 (사용자가 여러 번 강조)**: 생성 결과에 **자막이 절대 없어야 함**.
5. **추가 요구 (마지막에 명시)**: 인물만이 아니라 **배경·소품(요소) 디자인도 약간 바꿔야 함**.

## 4. 판별 방식 (사람 나옴 / 정면 설명형 제외)

1. Apify 결과의 `image_versions.scrubber_spritesheet_info_candidates`(인스타 스크러버 썸네일 시트)로 영상 다운로드 없이 12프레임 미리보기 생성 → `scripts/source_pipeline/build_pool.py`
2. Workflow(멀티 에이전트): 배치당 20개를 에이전트가 이미지로 보고 분류(`eligible / talking_head / no_people / slideshow_stock / animation_ai / other`, `remake_value` 0–10) → 키워드별 상위 16개를 **독립 반박 에이전트**가 재검증(불확실하면 탈락) → `scripts/source_pipeline/classify_workflow.js`
3. 통과작을 1차+검증 점수 합으로 정렬해 상위 10개 수집 → `scripts/source_pipeline/run_collect.py`
- 제외 기준 예시 이미지: 사용자가 처음 첨부한 영상(헤어밴드 여성이 핀마이크 들고 정면 설명 + 자막). 원본 파일은 세션 업로드라 저장소에 없음.

## 5. rea-video 사용 결과

- 설치: `pip install "rea-video[ocr] @ git+https://github.com/JuneYaooo/rea-video"` (별도 venv 권장). ffmpeg 필요.
- `rea-video models` 목록에 `kling-4.0-flash` 있음(≤20초, 멀티샷, 참고영상 지원).
- 사용 명령(소리·자막 분석 끔): `rea-video decompose <영상> -o <out> --no-vlm --no-stems --no-asr --no-speakers --no-moments --engine kling-4.0-flash --lang en` → `rea-video plan <out> --model kling-4.0-flash --generate all`
- 쓸모 있던 것: 샷 분할·샷 목록, Kling 프롬프트 작성 규칙(`capabilities/prompting.yaml`: [Asset Roles]→[Overall Settings]→[Sequence of Events]→[Audio], 부정 지시는 "자막 없음/음악 없음"만).
- **쓸모 없던 것**: VLM 없이 돌리면 실사 영상을 "AI 생성 70%"로 오판(사용자 목적상 무관). 자막 제거(`remake/refs/`)는 식단 영상에서 **자막은 남기고 화이트보드 글씨를 지움** → 사용 안 함.
- 클라우드에서는 한국어 OCR 모델(modelscope.cn), 얼굴 모델(GitHub raw) 다운로드가 막혔음.

## 6. 자막 제거·검사 (`igdm_digest/desub.py`)

- `remove_subtitles(src, dst, window=15)`: RapidOCR **검출 모델만** 사용(글자 인식 불필요). 자막 판정 = 글줄 높이 ≥ 화면 2%, 가로 중앙(±15%), 박스 안 매우 밝은(≥235) 픽셀 ≥ 7%. 화이트보드 손글씨(흰 바탕 어두운 글씨)는 밝은 픽셀 비율이 거의 0이라 제외됨. 앞뒤 ±15프레임 검출을 합쳐(흰 배경 위 자막처럼 OCR이 놓친 프레임 보완) `cv2.inpaint`.
  - 시행착오: (1) 흰 글자+검은 테두리 가정 → 이 영상 자막은 그림자형이라 실패, (2) 글자 크기만 기준 → 화이트보드 손글씨까지 지움, (3) 밝은 픽셀 비율 + 중앙 + 시간창 → 성공.
  - 한계: 지운 자리에 약간 번진 자국. 상단/구석 작은 자막, 색 있는 자막은 미검증.
- `scan_subtitles(video, every=1)`: 위 기준으로 자막형 글줄이 있는 프레임 수를 셈. **생성 결과 검수에 매번 사용.**

## 9. 중단 시점 작업 (다음 Claude 가 이어서 할 것)

사용자 마지막 요구: **인물 + 배경·소품 디자인 약간 변경, 자막 절대 없음.** 준비하던 방식(미실행):

1. 자막 제거된 참고영상에서 대표 프레임 추출(테스트: 현관 영상 3.5초, 9.5초).
2. Higgsfield `kling-image/v4.0/edit`(입력 `image_urls`, `@image_1` 로 참조; 공개 가격 없음 → estimate 로 확인)로 **같은 구도·포즈, 다른 인물·다른 인테리어** 키프레임 생성. 프롬프트 초안: `scripts/source_pipeline/prompts/test3_현관_디자인변경_이미지{1,2}.txt`
3. `kling-video/v4.0-flash/reference-to-video` 에 `image_urls`=[새 키프레임들], `video_urls`=[출력 길이로 자른 자막 제거 참고영상] → 프롬프트에서 "@Image 가 인물·공간 디자인, @Video 는 카메라·동작·타이밍만" 역할 명시.
4. 생성 후 `scan_subtitles` → 0건 아니면 `remove_subtitles` 후처리 후 재검사.
5. 결과를 레퍼런스 폴더 안 `리메이크/` 에 저장(원본·참고영상·키프레임·프롬프트·결과).

그 밖의 남은 일:
- 보충 검색 결과(3절) 판별 → 장보기·재테크 채우기, 장보기 오분류 2건 재검토.
- 58개 전체 리메이크는 **사용자 확인 후**(비용: 10초 기준 1개당 약 $1.26).
- 코드 브랜치 `claude/source-collect-remake` 는 아직 `main` 미병합.
- 사용자 전역 규칙("정확성·검증 우선 응답 원칙")은 클라우드에선 유지 안 됨 → **로컬 PC `~/.claude/CLAUDE.md` 에 설치 필요**(사용자 요청 사항, 미완료).
