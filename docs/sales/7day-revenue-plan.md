# 7일 매출 플랜 — 숙박업 홈페이지 + 홍보영상 패키지

목표: 7일 안에 실제 입금 100만원. 방법은 "빠르게 현금화되는 서비스 판매" 하나로 좁힙니다.
쇼핑몰·해외 Shopify·릴스 직접 수익화는 이번 주 목표에서 제외합니다 (근거는 맨 아래).

## 1. 무엇을 파는가

| 상품 | 내용 | 가격(제안) | 납기 |
|---|---|---|---|
| 스타터 랜딩 | 모바일 1페이지: 대표 사진·객실 요약·가격·지도·전화/네이버예약 버튼·인스타 피드 연결 | 39만원 | 3일 |
| 스탠다드 홈페이지 | 5페이지(메인·객실·주변·오시는길·예약안내) + 실시간 예약 링크 연동 + 기본 SEO + 네이버 플레이스 연결 | 79만원 | 7일 |
| 영상 애드온 | AI 홍보 릴스 3편(Higgsfield), 세로 9:16, 15~30초, 자막 포함 | 25만원 (단독 30만원) | 3일 |
| 유지관리(선택) | 월 1회 사진·가격 수정, 도메인/호스팅 관리 | 월 5만원 | - |

- 첫 2건은 "포트폴리오 조건" 으로 20% 할인해도 됩니다. 대신 후기와 사례 사용 동의를 받습니다.
- 결제: 착수금 50% 입금 확인 후 작업 시작, 잔금은 오픈 당일. 수정 2회 포함, 추가 수정은 회당 3만원.
- 목표 산식: 스탠다드 1건 + 스타터 1건 = 118만원. 또는 스타터 2건 + 영상 1건 = 108만원.

가격 근거 (시세, 2026-10 검색 기준):
- 아임웹 기반 15페이지 "전체세팅형" 55만원, 제작 3~5일 (아임웹 전문가 리스팅)
- 크몽 펜션 전용 홈페이지 프리미엄 패키지 330만원 + 월 관리비 22만원 (크몽 리스팅)
- 크몽 쇼츠/릴스 제작 1만·5만·10만원 패키지 (가격 경쟁 심함 → 영상은 단독보다 끼워팔기)
→ 홈페이지가 객단가가 높고, 1인이 템플릿으로 3~7일 안에 납품 가능한 가격대가 39~79만원입니다. 위 가격은 시세를 바탕으로 한 **추정 제안가**이며, 실제 상담에서 조정합니다.

## 2. 누구에게 파는가

- 1순위: 자체 홈페이지가 없고 야놀자·여기어때·네이버예약·에어비앤비에만 의존하는 펜션/풀빌라/독채. 플랫폼 수수료를 아끼고 싶은 동기가 분명합니다. (플랫폼 수수료율은 업체마다 달라 이 문서에서는 수치를 단정하지 않습니다)
- 2순위: 홈페이지가 있지만 모바일 미대응·낡은 디자인·예약 버튼 없음.
- 3순위: 식당·카페·공방 등 예약/문의가 매출인 소상공인.
- 리드 목록은 `docs/sales/leads-*.md` 에 쌓습니다. 공개된 사업 연락처만 사용합니다.

## 3. 7일 일정

| 일 | 할 일 | 목표 수치 |
|---|---|---|
| 1일차 | 리드 30곳 확보(리드 문서 + 직접 검색), 데모 페이지 링크 준비, 1차 발송 15곳 | 발송 15 |
| 2일차 | 2차 발송 15곳, 전화 10곳, 응답 처리 | 발송 30 누적, 응답 3 |
| 3일차 | 상담 → 견적서 → 착수금 요청 | 상담 2, 착수금 1 |
| 4~6일차 | 제작(템플릿 기반), 중간 화면 공유, 2차 영업 계속 | 착수금 2 누적 |
| 7일차 | 오픈 + 잔금 + 후기·사례 확보 | 입금 100만원 |

응답률은 보통 한 자릿수 퍼센트입니다(확인된 통계가 아니라 일반적 경험치). 30곳에 보내면 2~3곳 응답, 1곳 계약이 현실적인 기대치이므로, 3일차까지 응답이 없으면 50곳으로 늘립니다.

## 4. 접촉 채널 (응답률 높은 순)

1. **전화** — 펜션 사장님은 전화에 가장 잘 응답합니다. 오전 10~11시, 오후 3~5시.
2. **인스타그램 DM** — 업체 계정이 활발하면 사진 칭찬으로 시작.
3. **네이버 톡톡 / 카카오 채널** — 플랫폼 문의 버튼.
4. **이메일** — 공개 이메일이 있을 때만. 응답률 가장 낮음.

하루 20~30건까지만, 반드시 업체 이름과 구체적 상황을 넣어 개인화합니다. 복붙 대량 발송은 스팸 신고로 이어집니다.

## 8. 이번 주 제외한 것과 이유

- 해외 Shopify: 검색 기준 Shopify Payments 가 한국 미지원이라 제3자 결제 연동이 필요하고, 상품·광고비가 먼저 들어가 첫 주 수입이 나기 어렵습니다. 4주 과제로 미룹니다.
- 릴스 직접 수익화: 한국 공식 수익화 도구는 기프트·구독이고 보너스는 초대제 시범 운영입니다. 신규 계정의 첫 주 직접 수익은 0으로 봅니다. 릴스는 이 서비스의 문의 유입 채널로 씁니다.
- 국내 쇼핑몰(매출 0): 원인 분석 없이 광고비를 넣으면 손실 가능성이 큽니다. 서비스 매출이 생긴 뒤 DM 다이제스트로 모은 정보를 바탕으로 실험합니다.
