# 데모 자산

## 데모 랜딩 페이지 (가상의 "바다결 펜션")

- 제안 메시지의 {데모 링크} 자리에 넣는 페이지입니다. 링크는 이 문서 아래 "게시 링크" 에 기록합니다.
- 사진 자리는 노을·바다 그라데이션과 '사진이 들어갑니다' 표시입니다. 아티팩트 보안 정책상 외부 이미지를 불러올 수 없고, 이 작업 환경의 네트워크 정책이 Higgsfield 에서 만든 이미지 다운로드를 막아 넣지 못했습니다.
- 페이지 원본: `docs/sales/demo/badagyeol.html` (사진은 `window.PHOTOS = {hero:..., room1:..., room2:..., room3:..., terrace:...}` 로 넣음)

## Higgsfield 로 만든 샘플 사진 3장 (0.75 크레딧 사용)

Higgsfield 계정의 생성 기록에서 내려받아 페이지에 넣을 수 있습니다. 모델: gpt_image_2_5.

1. 외관(바다 배경, 골든아워, 3:2) — job 69d1bbdc-a2fd-4db6-8814-b0a04f957ba5
2. 객실 내부(바다 창, 4:3) — job 0ec4d4f5-a88d-42e2-8459-133309db6756
3. 테라스 노을(16:9) — job 11e01c0d-22ab-466f-9315-45c2fd1d40fe

페이지에 넣는 방법: 세 파일을 `docs/sales/demo-photos/` 에 `hero.jpg`, `room.jpg`, `terrace.jpg` 로 올려 두면(GitHub 웹에서 드래그 업로드 가능) Claude 가 데이터 URI 로 바꿔 넣고 다시 게시합니다.
